# Comprehensive Rules — September 25, 2026

Official text: `server/context/magic-comprehensive-rules.txt` (effective September 25, 2026). Use this digest for rules and new-set questions. Prefer these rules over older training data.

## New card type: Preparation Cards (rule 722)

Preparation cards have a two-part frame. The inset frame on the right is a **prepare spell** (alternative characteristics). The card’s normal characteristics stay on the left.

- You cannot cast the card using the prepare-spell characteristics. Those define copies that may be cast later.
- Becoming **prepared** (or entering prepared) gives the permanent the prepared designation if it has a prepare spell.
- **Unprepared** removes that designation.
- When a permanent becomes prepared (or phases in prepared), its controller creates a copy in exile that has only the prepare-spell characteristics. They may cast that copy. The permanent loses prepared when that spell is cast.
- In every zone, a preparation card has only its normal characteristics.
- Later additional-rules numbers shifted by one: The Monarch is now **725**; Handling Illegal Actions is **733**.

## New keyword action: Empower Jace (rule 701.71)

To **empower Jace N**: if you don’t control a Jace planeswalker token, create a blue Jace planeswalker token with 0 loyalty, `[−1]: Surveil 1`, and `[−3]: Draw a card`. Then choose a Jace planeswalker token you control and put N loyalty counters on it.
